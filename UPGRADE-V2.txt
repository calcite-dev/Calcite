CALCITE V2 — upgrade from V1

1. Back up your current GitHub files and Supabase data. Keep your existing config.js, logo.jpg, videos.json and database. This ZIP deliberately excludes config.js and the original schema.sql. Do not rerun schema.sql.
2. Open upgrade-v2.sql in Notepad, copy all SQL into Supabase SQL Editor, run once. It replaces the save_section function to permit the new Website fields. Existing content, accounts and permissions remain in place. No new tables.
3. Extract this ZIP. Upload the contents to the root of your existing GitHub repository, preserving directory paths. Confirm replacing the matching V1 files. Do not delete your existing config.js, logo.jpg or videos.json. If you use GitHub Actions hosting, replace .github/workflows/pages.yml as well; otherwise leave your existing branch-based Pages deployment settings alone. If GitHub web upload skips dot folders, use the existing workflow editor to paste the updated workflow manually.
4. After deployment, test homepage, /content/, /calendar/, /contact/ and /admin/ using your existing Pages URL. Sign in with the existing owner account. Studio > Website contains the Page Builder and Themes. Save draft there, then Dashboard > Publish saved drafts. Feature toggles still hide optional pages. Custom pages use ?page=... URLs. Standard pages have separate directories. Preview uses an iframe; link navigation within it can interrupt preview. Use Refresh preview or reopen the editor.
5. Test a restricted account: Website permission is required to save page/theme changes, Publish permission to publish. Ensure anonymous users cannot read drafts or applications. Keep applications disabled until moderation and spam/privacy protections have been reviewed. Do not change DNS until tested.
6. Theme scheduling uses UTC calendar dates, last overlapping schedule wins. Visitor choices use localStorage, with no account. Preference is local to each browser and origin. Themes are lightweight CSS palettes/gradients and subtle effects, not elaborate illustrations.

Scope: existing V1 functionality retained. V2 adds page routes, custom pages, navigation ordering, block editing with drag and drop, structural undo/redo, in-memory visual preview, six seasonal presets and custom accent, theme dates and light/dark/system. Some built-in labels remain fixed; image blocks use HTTPS URLs rather than uploads. Undo/redo covers structural changes, not every keystroke. No autosave, timed content publishing, individual-page permissions, complete custom themes, analytics, media library, contact inbox or UI version recovery yet. Existing YouTube sync and user management still require their V1 setup. The current GitHub branch-based setup will not run the RSS workflow automatically unless configured for Actions. JavaScript syntax and relative paths checked; live Supabase and browser behaviour not tested. Keep V1 backup.
